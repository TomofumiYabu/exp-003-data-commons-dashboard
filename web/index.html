    05 / INTERPRET WITH CARE

    Limitations

      Experiment method

      EXP-003 evaluates statistical research through MCP, autonomous analysis and static delivery. The workflow resolves indicators and countries, checks metadata, selects consistent World Bank facets and retrieves bounded annual series. Changes are end minus start; relative changes are 100 × (end / start − 1). Missing values remain missing.

      The web-only research baseline is a sequential comparison with shared prior context, not a blinded trial. This dashboard reports the MCP dataset. Research findings do not establish causation or an overall MCP advantage.
